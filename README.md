## Описание проекта

Android-приложение «Больница» для управления данными о пациентах, врачах, отделениях и диагнозах. Приложение реализовано с использованием современной архитектуры **MVVM** и библиотеки **Room**.

### Основной функционал (КР):
- Просмотр списка отделений через Spinner
- Просмотр списка врачей выбранного отделения
- Просмотр списка пациентов по выбранному диагнозу
- Кастомный RecyclerView-адаптер с иконками
- Локальная база данных Room с начальными данными (seed)

### Дополнительно выполнено (ИПР):

**Интеграция с системным календарём (Calendar Provider)**

- Добавлены разрешения на чтение и запись в календарь
- В карточке пациента/врача добавлена кнопка **«Записать в календарь»**
- При нажатии открывается стандартное окно создания события с предзаполненными данными:
  - Название события
  - Описание (ФИО пациента + диагноз)
  - Дата и время (на следующий день)
- Корректная обработка разрешений пользователя

## Технологии

- **Kotlin**
- **MVVM** (ViewModel + StateFlow)
- **Room** (Entity, DAO, Database, Repository)
- **View Binding**
- **RecyclerView + ListAdapter + DiffUtil**
- **Kotlin Coroutines**
- **CalendarContract + Intent** (для ИПР)

## Структура проекта

- `data/entities` — сущности Room
- `data/database` — база данных и DAO
- `data/repository` — репозиторий
- `viewmodel` — ViewModel
- `ui` — адаптеры и binding
