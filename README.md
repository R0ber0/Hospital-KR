## Описание проекта

Android-приложение для управления больницей с использованием Room Database, MVVM архитектуры и RecyclerView.

### Реализованные функции:
- Выбор отделения и просмотр списка врачей
- Выбор диагноза и просмотр списка пациентов
- Кастомный RecyclerView адаптер с иконками
- Локальная база данных с начальными данными

## Технологии
- Kotlin
- Room + DAO + Repository
- MVVM + ViewModel + StateFlow
- View Binding
- RecyclerView + ListAdapter

## Что было сделано:
- Сущности: Department, Doctor, Diagnosis, Patient
- Связи между таблицами
- Seed данных при первом запуске
- Фильтрация по отделению и диагнозу
